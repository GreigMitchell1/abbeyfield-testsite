# Abbeyfield Scotland – Node.js Website

A simple, accessible, brand‑styled website for a charity supporting older people in Scotland.

## Features
- Node.js + Express + EJS
- Public pages (Home, About, Services, Locations, Contact)
- Members‑only section with password gate via `.env`
- Animated **GIF** logo included in header (`/public/images/animated_logo.gif`)
- Responsive, accessible design using Abbeyfield colour palette

## Setup
```bash
npm install
# create .env (already included with a sample password)
npm start
```
Site will run at http://localhost:3000

## Environment
- `MEMBER_PASSWORD` — password for members area

## Deploy
- Push to GitHub
- Deploy on Render/Heroku/Azure App Service or similar
